# 测试与已知限制 / QA and known limits

Generated for v2.1. This file is a working checklist, not a claim that every historical entry has been independently peer-reviewed.

## 已完成的验收路径

| 场景 | 步骤 | 结果 |
| --- | --- | --- |
| 1945 时间轴停靠 | 从 1944 拖到 1945（或 `atlasAPI.setYear(1945)`） | 自动打开日本 1945 事件组，播放广岛核爆，右侧显示详情 |
| 1945 点击日本 | 点击日本国土（或事件节点） | 打开同一事件组；面板列出 9 条相关事件，可逐条播放 |
| 事件详情 | 事件组中的“广岛原子弹” | 显示日期、地点、参与方、背景、经过、结果、来源、校验状态 |
| 面板滚动 | 在右侧面板内滚动鼠标滚轮 / 触控板 | `scrollTop` 增加，地图缩放不变 |
| 面板关闭 | 右上角 ×、左侧箭头、Esc | 面板收起；可点“此刻世界”重新打开 |
| 地区导航 | 点“欧洲” | 相机定位欧洲；年份和面板状态保留 |
| 历史名称 | 1500 年 | 显示明、日本、阿兹特克、印加、澳洲原住民等；不显示现代“澳大利亚” |
| 1770 年 | 美洲 | 显示英属北美殖民地、新西班牙、葡属巴西；不显示“美国” |
| 2026 年 | 全球 | 只显示现代国家实体，201 个现代国家标签进入候选池；台湾省作为中国省级实体显示 |
| 手机 | 390×844 | 顶栏不横向溢出，地区条可横向滚动，面板和关闭按钮在视口内 |
| 事件弹窗 | 点“展开史志” | 弹窗内增加背景/经过/结果/来源区块 |
| 重复点击 | 连续点同一事件 | 600ms 内去重；剧场状态重置，不叠加 |

## 已知限制

- 历史实体覆盖来自 18 个全球快照 + 现代国家形成年 + 61 个策展实体。快照之间的年份使用近似区间，已标 `approx: true`；没有命名实体的地区会留空，不强行显示现代国名。
- 前 3000 年以前、太平洋小岛和部分原住民群体的名称覆盖不足；需要继续补专门数据，不能靠推测填补。
- 中文模式只显示已收录中文名的实体；尚未收入 `name_gloss.json` 的冷门族群会暂时留空，不以英文冒充中文。
- 事件详情目前有 45 条完整七段式（截至本次构建）；其余重点事件是结构化简版，界面明确标“简要条目 / 长文待补”，不会伪造背景。
- 现代国名为可选辅助层，默认关闭；打开后仍受历史图层缩放规则约束。
- 台湾在数据中作为中国台湾省处理：中华民国实体只到 1949 年；1949 年后仅显示“台湾省”，不作为现代国家，也不参与国家新生计数。
- 中国江山时序是统一专题模式，不是对 DeanChensj 原作的逐像素/逐数据复刻；没有引入省级历史边界或原作内容。
- 生成式动态对没有专属剧场的事件使用示意动画；界面会标注“示意/无”，不声称是考古复原。
- 事件详情的新增长文以中/英文为主；ES/FR/AR 目前回退英文，已有事件的摘要翻译保持原状。
