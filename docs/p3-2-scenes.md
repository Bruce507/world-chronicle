# P3-2 场景扩量种子批次 / Scene expansion seed batch

Date 2026-11-07. **这不是 Gate 3 完成**：没有新增插画级 Hero 场景，也没有 100–150 个变体或盲测。本轮只把现有 Tier B 家族（siege / caravel / modern）扩展到更多重点事件，并提升其中两个地图场景的构图。

## 1. 数量

| 项 | P2 | 本轮 |
|---|---:|---:|
| Hero 场景 | 32 | **32**（未变） |
| Tier B 变体 | 29 | **45**（+16） |
| 视觉家族 | 56 | 56（未变） |

新增 16 个变体（均为参数变体，复用现有绘制代码）：

- modern：拉丁美洲独立、1848 革命、德国统一、海地革命、墨西哥革命、辛亥革命、土耳其共和国、越南独立宣言、古巴革命、孟加拉国独立、伊朗革命、结束种族隔离、香港回归、阿拉伯之春（14）
- siege：阿兹特克覆灭（1）
- caravel：西班牙无敌舰队（1）

斯大林格勒曾被试列为 siege 变体，但 1942 年城市战套用中世纪城墙会误导，已移除；它继续使用通用 war 剧场。

## 2. 地图场景改进

- **modern**：从“一个国会矩形 + 4 个人”改为有纵深的广场——两侧城镇剪影、透视铺地、带台阶/柱廊/山花的议会、两面旗帜、11 人人群与彩纸；所有 6 个原有 modern 变体同步受益。
- **caravel**：增加海平线、日光、五道涌浪、flagship（1.12 倍）与僚舰（0.48 倍）、海鸥；所有 caravel 变体同步受益。
- 这两个改进是共享家族代码，不是逐事件插画；因此质量上限仍低于 Hero。

## 3. 验证

- `VariantScenes.list()`：45 个 id，0 个找不到对应事件。
- 打开辛亥革命、西班牙无敌舰队、阿兹特克覆灭：variant 生效、剧场 active、无控制台错误；截图见 `docs/p3-shots/p3-2-tierb-*.jpg`。
- `npm run smoke`：Tier B 计数更新为 45；其余回归通过。
- 16 秒静态末帧、390×844、reduced-motion 沿用现有测试。

## 4. 未完成 / 为什么

- **Hero 30→60 未做**：每个 Hero 场景是独立的 stage + map 构图，需要插画级设计与多轮复审；本轮没有足够产能，也不应批量生成低质场景。
- **Tier B 100–150 未做**：新增家族（cavalry / city / monument / revolution / disaster）需要新的舞台与地图绘制代码，不是参数变体。
- **盲测未做**：新增 16 个变体没有经过 6 人盲测，不能宣称达到 Gate 3；它们只是扩大了覆盖，质量与现有 Tier B 持平。
- 现代政治变体仍共用“议会 + 广场”构图，事件之间差异主要靠旗帜颜色、天空与人群，达不到 Hero 的叙事差异。
- caravel 变体仍是单/双船 + 海岸，未按事件区分（无敌舰队、五月花、库克）。

## 5. 下一步（Gate 3 真正开工时）

1. 先做 3 个新家族的 pilot：cavalry（骑兵/草原）、city（城市/港口）、disaster（火山/瘟疫），每个 3–5 个变体；
2. 为 pilot 做 6 人盲测，均分 ≥4.5 才扩量；
3. 把 45 个变体按事件逐一检查构图适配，移除“家族套错”的变体；
4. Hero 扩量另开插画批次，不与 Tier B 共用验收。

## 6. 第二轮：全量接触表与多样性审计（2026-11-07）

本轮不新增场景，只把现有 32 Hero + 45 Tier B 全部渲染出来做质量与多样性复核，避免"数量已够"的错觉。

- 全量接触表：`docs/p3-shots/p3-2-hero-contact.jpg`（32 格）、`docs/p3-shots/p3-2-tierb-contact.jpg`（45 格），每格取第 8 秒的 `drawStage` 静态帧，240×150。
- 结果：**77/77 全部有画面，0 个空白格**，无绘制异常（红色占位格未出现）。
- 多样性（64×40 缩略图逐像素平均差异，0 = 完全相同，1 = 完全不同）：

| 组 | 数量 | 平均两两差异 |
|---|---:|---:|
| Hero | 32 | **0.170** |
| Tier B 全部 | 45 | **0.107** |
| Tier B · modern 政治 | 18 | **0.062** |
| Tier B · siege | 16 | **0.063** |

结论（写入验收结论而非宣传）：
1. Tier B 内部差异只有 Hero 的约 **37%**；同一家族内主要靠旗帜、天空色调与人群数量区分。
2. 16 个 siege 变体共用一个"城墙 + 帐篷 + 旗"构图；其中 1937–38 的中国战场（淞沪、台儿庄、武汉、百团）与 1942 年城市战套用中世纪城墙，与上一轮移除斯大林格勒的理由同源。**本轮不删除它们**（约束要求 Tier B 保持 45 可用），但列为已知质量缺陷，P4 的 Gate 3 必须一并处理。
3. 因此 45 个变体仍只能称为"种子批次"，不能宣称 Gate 3 达标；也没有做盲测。

Gate 3 若要开工，建议先在 siege 家族内部拆出 `urban-war`（近代巷战）子家族，再谈扩量。
