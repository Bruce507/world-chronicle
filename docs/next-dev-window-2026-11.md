Date 2026-11-08。本文件是给下一个开发会话的交接：**当前是否"完成"、哪些还能做、哪些做不了**。

- 最新提交 `eea9f5b`，CI 全绿：静态检查、生成物一致、内容、a11y（21 项）、data-qa（含 tier）、性能预算、entity-i18n、smoke（60 项）、PWA（7 项）；Pages 部署成功，线上 200。
- 521 事件 / 56 视觉家族 / 32 Hero / **57 Tier B** / 112 完整史志 / 6 路线 / 250 来源（机构 26.0%）/ 实体标签显示覆盖 95%。
- 三轮复盘共 27 项（D1–D20、U1–U22）：P3、P4 两轮全部修复或说明；P2 遗留 D2、D4/U4、D7、U3、U8 仍是"部分"，原因各有记录。

## 2. 设计师视角：完成度

**成立的部分**

- 一套印刷语言贯穿地图、剧场、面板与共享卡片，没有"拼装感"；
- 导航只有一个心智模型：年份 → 地区 → 国家（含并立政权）→ 事件 → 史志；专题模式已并入国家镜头；
- 版式层级现在清楚：工具组与地区行分开、地区标签、字号下限 9.5–10px、来源按机构优先；
- 场景的"家族 + 子构图"结构能持续扩量（本轮 57 个变体，disaster 家族内部差异 0.126）。

**仍未完成的部分（不掩饰）**

- **三层质量断层仍在**：32 个 Hero 与 57 个 Tier B 之间是插画级与版画级的差距，Tier B 内部同剪影的变体仍主要靠旗帜与配色区分；盲测从未做。
- **D7 的尾巴**：图例计数、角标、纪元带等装饰性文字仍有 8–8.5px。
- **D4/U4 的尾巴**：双击时代带、Alt+滚轮仍是隐藏手势，界面上没有对应入口。
- **内容密度不均**：409 条简要条目与 112 条完整史志并列，用户点开一个"看着重要"的事件却发现只有两段话。

## 3. 使用者视角：体验

**顺的路径**：搜索 → 事件 → 剧场 → 史志；收藏与备份；分享卡片；离线状态；中文/英文界面；中国镜头里 1200 年直接看到宋/金/西夏。

**仍会卡住的地方**

- ES/FR/AR 用户：界面是本地化的，但**长文与大部分简要条目仍是中英**；
- 离线：只保证已访问过的内容，未访问的事件只有摘要（已明示，但仍是限制）；
- 手机：半屏 213px 地图 + 列表，是刻意的取舍；iOS 的安装、离线和分享**没有真机验证**；
- 低端机：模拟 6.7 秒可交互，真机会更慢或更快，不知道。

## 4. 剩下的事：哪些我们还能做，哪些做不了

### 还能做（不需要外部资源）

1. **WebKit（Safari 引擎）回归**：Playwright 自带 WebKit，可跑 smoke 的关键路径与 PWA 检查，提前抓 Safari 专属问题（不能替代真机，但比没有强）。
2. **无障碍树与键盘走查**：用 `page.accessibility`/DOM 生成可访问性树快照，核对读屏顺序、名称、live region；补 400% 缩放与高对比组合检查。
3. **D4/U4 收口**：为"双击时代带""Alt+滚轮"加显式按钮或菜单项，去掉最后的隐藏手势。
4. **D7 收尾**：把 8–8.5px 的装饰性文字提到 ≥9.5px 或改成非文字（色块/线），并跑对比度抽样。
5. **翻译续做**：实体标签还有约 1,200 条未译，可按频次继续（低风险、可度量）；长文翻译仍不建议无母语审校时推进。
6. **机构来源**：继续逐条检索并核验（慢，但可推进）；目标是先到 35–40%，60% 需要领域编辑。
7. **简要条目扩写**：按"2 个可核验来源"的规则先做 10–20 条 featured，而不是批量。
8. **错误日志（可选、隐私友好）**：本地 ring buffer + 用户手动导出，不接第三方；需所有者确认是否要。

### 做不了（缺外部条件，不要假装能做）

- **真机性能/内存/发热**：需要低端 Android、iPhone SE/Safari 或云真机账号；CDP 模拟不能替代。
- **NVDA（Windows）实测**：本机没有 Windows 环境；VoiceOver 需要人工听读与辅助功能授权。
- **iOS PWA 安装/离线/分享**：需要 iPhone。
- **母语审校**：ES/FR/AR 长文需要母语者，机器翻译会违反"不伪造"。
- **盲测（Gate 2/3）**：需要 ≥6 名评审。
- **Hero 30→60**：需要插画产能。
- **错误监控服务选型、机构来源 60% 目标**：属于所有者决策/领域编辑工作。

## 5. 建议顺序（下一窗口）

1. WebKit 回归 + 无障碍树走查（一次做完，产出 `docs/webkit-a11y-2026-11.md`）；
2. D4/U4 显式控件 + D7 字号收尾（两项都小，可一起提交）；
3. 实体标签再补 100–150 条 + 机构来源核验一批；
4. 10–20 条 featured 简要条目扩写（每条 2 个可核验来源）；
5. 其余保持"未验证"标记，等设备与人员。
