# 本轮复盘（设计与使用者视角）/ Final review 2026-11-08

范围：D2 画面差异、盲测包、UX 收口、roving tabindex、实体标签第二批、20 条 featured 史志、机构来源回补。结论先说：**工程、交互、无障碍与内容层能做的已经做完；产品层仍有三类不能在本机完成的外部验证。**

## 1. 设计师视角

### 变好的地方

- **Tier B 的剪影终于能读事件**：现代阳台（山花/瓦顶/檐廊/柱廊/女儿墙）、街垒（教堂/工厂/棕榈/钟楼/城门/宣礼塔）、议会厅（雕像/穹顶天窗/时钟/旁听席）、广场（殖民拱廊/海港/城市）不再只靠旗帜区分。
- **灾害场景拆开了**：里斯本是河岸双塔、关东是倾斜木屋与火灾、墨西哥是中层街区；印度洋是渔村、福岛是厂区/海堤/输电塔。以前三张地震几乎一样。
- **时间轴不再需要说明书**：时代下拉 + 明确的"时间轴 − +"组，隐藏手势有了可见入口。
- **排版层次**：全站 9.5px 下限、时代带对比度、`史志` 金色标记，让"这一条有长文"在列表里就能看见。

### 仍然不够好的地方

- **Tier B 与 Hero 的差距还在**：像素差异 0.133 对 0.177，插画级与版画级的区别没有被消除。本轮加的是剪影，不是插画质量。
- **同家族仍共享舞台**：siege 的城墙/营地、modern 的人群/街道仍是同一套语法；`balcony` 的 64×40 灰度差异只有 0.035，人眼能分辨，但远看仍像一个模板。
- **地图徽章没有完全跟上**：新的立面/地标主要画在剧场舞台，地图上的小徽章仍按原结构（议会有拱窗、街垒有沙袋）；这是本轮新发现的**一致性缺口**，不影响可读性，但下一轮应同步。
- **blind test 未做**：盲测包已生成，但没有 6 名非项目评审，不能把"差异度"当成"已达标"。

## 2. 使用者视角

- **顺的路径**：搜索 → 事件 → 剧场 → 史志依旧最顺；`史志` 标记让用户知道点开有没有长文。
- **手机**：390×844 半屏 5 行、无横向溢出、时间轴标签隐藏但 aria 名称保留；2026 仍能一眼看到"现代国家 196"。
- **内容**：147 条完整史志 / 374 条摘要。高频事件大多有长文，但仍有大量次要事件只有两段话；`史志` 标记是诚实提示，不是填补。
- **多语言**：实体标签 60%、实际显示 98%；冷僻原住民群体名保留英文。ES/FR/AR 用户点开长文仍会遇到中英内容——这是目前最大的语言墙。
- **无障碍**：Tab 到时间轴 123 → 39；事件列表/政权 chip/地区 chip/地图节点各一个停靠点，方向键组内移动且不再误改年份。读屏人工听读仍未做。

## 3. 本轮发现并修掉的新问题

| 问题 | 原因 | 修复 |
|---|---|---|
| 乔治式山花/瓦顶在舞台顶部被裁掉 | 舞台可见范围是 y ≥ −62.5，原建筑顶部在 −66 | 建筑顶降到 −54，屋顶画在 −54…−62 |
| 事件行里按方向键会改年份 | 事件行只 `preventDefault`，全局方向键仍执行 | 行/ chip / 节点导航统一 `stopPropagation` |
| 2026 半屏第 5 行只剩 0.2px 余量 | 字号提升后行高变化 | 行距/分类行各压 1px，余量约 11px |
| `variant-scenes.js` 超出单文件预算 | 逐事件剪影新增 3KB | 单文件预算 26 → 32KB（懒加载总量 113/120 仍有余量） |
| 事件列表 62 个 Tab 停靠点 | 每行都是按钮 | roving tabindex，列表只保留 1 个停靠点 |
| 时代面板“此刻”标签被分类行遮住（上一轮遗留） | 固定 76px 偏移 | 按粘性分类行实测高度 + 22px |

## 5. 仍然不能在本机完成（明确保留）

1. **6 人盲测**（Gate 2/3）：包已就绪，评审未到位。
2. **真机**：低端 Android、iPhone/Safari、iOS PWA 安装/离线/分享。
3. **屏幕阅读器**：NVDA（Windows）/ VoiceOver（人工听读）；清单见 `manual-verification-2026-11.md`。
4. **母语审校**：ES/FR/AR 长文；147 条史志仍只有中英。
5. **Hero 32 → 60**：需要插画产能。
6. **机构来源 35–40%**：当前 26.0%，需要领域编辑逐条替换。
7. **错误监控**：需所有者决定第三方与隐私策略。
8. **地图徽章与舞台剪影同步**：新发现的一致性缺口，建议下一轮做。

## 6. 结论

**可以作为"现阶段完成"**——前提是把完成定义为：*代码、交互、无障碍、内容与来源在本机可验证的范围内全部收口，且所有未验证项都被明确标注*。

不能称为"产品完成"：Tier B 的画面质量仍低于 Hero，374 条摘要仍是内容债，外部设备/读屏/母语/盲测一项都没做。下一步优先级建议：

1. 推送并确认 CI 绿（资源版本 `20261109b`）。
2. 做一次 6 人盲测；若 siege 或 balcony 低于 6/10，先修这两个子构图，不扩量。
3. 用 Mac 的 VoiceOver 与一台 iPhone 完成人工验证清单。
4. 机构来源按每批 10–15 条替换，目标先回到 30%，再谈 35%。
5. 同步地图徽章与舞台剪影；之后再考虑 Hero 扩量。
