# 交互精修实施记录 / Interaction pass

Date 2026-11-07. Implements the P0/P1 backlog in `docs/ux-review-2026-11.md`, then resumes the content audit. 之后的第二轮（手机铺满、刻度降噪、RTL、内容 521、长文 52）见 `docs/next-stage-2026-11.md`。

## 1. P0-1 时间轴精确化（commit `da7e722`）

- 年份读数可点击，展开数字输入（接受 `1937`、`前1937`、`-1937`、`1937 BCE`）；左右 `−/+` 步进一次一年。
- 键盘：`←/→` 按当前年代自适应步长（100/25/10/5/1 年），`↑/↓` 恒为 ±1 年，`Alt+方向` 也是 ±1，`Shift` ×10；提示文案按当前步长实时显示。
- 轨道 hover/scrub 显示“年份 + 最近事件”；点击事件刻度（9px / 触屏 16px 内）吸附并打开该事件。
- 放大：`聚焦近现代`（1750–2026）、双击时代带进入该时代、`Shift` 拖出区间刷选、`Alt+滚轮` 以指针为锚缩放。缩放窗口内仍按时代权重分配宽度（保留非线性比例），窗口 ≤160 年时绘制年份标尺。
- 播放头菱形移到轨道上方，不再压住时代标签；拖动时间轴会退出旧的“当前事件”表面。
- 轨道是 `role="slider"`，带 `aria-valuemin/max/now/valuetext`，可 Tab 聚焦并用方向键操作。

## 2. P0-2 历史标签收敛（commit `ef9aa86`）

- 新增 `data/entity_clamps.json`（141 条按名年限/改名 + 5 条按 id 修正 + 7 条删除）：清 1620–1912、中国军阀 1916–1928、苏联 1922–1991、俄罗斯帝国→1917、日本帝国→1947、安南→1945、英属印度→1947、中亚诸汗国→1920、吐蕃→842 等；构建脚本与 `js/entities.js` 双重应用，旧缓存也不会复活过期标签。
- `CURATED_ALIASES`：当 curated 实体覆盖同区时压制 basemap 的旧名/宗主国名（清/中国/中国军阀、日本帝国、法属印度支那、英属马来亚、荷属东印度等），1937 年不再同时出现“清”“中国军阀”“中华民国”。
- 标签优先级按 `priority + sqrt(area)` 计算；加入碰撞上下偏移、节点徽章避让、移动端更低的标签上限；地图标签最小字号 10/10.4px。法国、德国补了连续 curated 标签（843/1871–2026）。
- 事件“地点”改为两行：主地点（如“日本广岛”）+ `今 <现代国名> · 当时 <当时政权>`。当时政权来自 curated 实体、事件年份对应的疆域快照多边形（经实体年限校验）与事件国家代码 scoping；1937 年卢沟桥/南京/淞沪显示“当时 中华民国”，1945 广岛显示“当时 日本帝国”，青藏/新疆等按国家范围匹配。

## 3. P0-3 事件表面统一（commit `231312f`）

- 右侧面板是唯一详情表面：点击节点 → 设置年份、打开面板、播放地图剧场。
- 地图浮动卡缩为“年份/类别 + 标题 + 展开史志 + 暂停”，面板打开时自动隐藏；关闭面板后作为 peek 卡保留。
- 手机端面板改为底部抽屉：peek（136px）/ half（58% 地图高度）/ full（88%），保留地图与剧场在抽屉上方；拖动把手或点击循环三档，双击切换 half/full；地图相机随抽屉上移，聚焦节点不被遮住。
- 面板头直接显示事件标题（peek 状态也有意义），正文不再重复标题；增加“朗读”；完整史志只经“展开史志”进入弹窗。
- 修复：面板/卡片/缩放按钮上的 `pointerup` 冒泡触发地图 picking，导致点击被吃掉、事件被意外关闭。

## 4. P1（commit `d743a4e`）

- 节点聚合：低缩放按屏幕距离聚类，徽章显示数量与类别色点；hover 列出成员，点击放大；触屏命中区 26px。
- 类别筛选：时代/中国面板顶部 sticky 筛选条，作用于地图节点、时间轴刻度与事件列表；筛选变化后回到筛选条。
- 面板 IA：筛选 + 时代节点列表在前，并立文明/国家兴亡在后；默认滚动到“此刻”分隔线。
- 搜索：`↑/↓` 选择、`Enter` 打开、`Esc` 关闭；`role=listbox/option` 与 `aria-activedescendant`；结果点击同时定位年份、打开面板并播放剧场。
- 首次进入：桌面默认展开时代摘要；三步引导卡（一次性 localStorage 标记）；“看凡例”直达。
- 凡例新增事件类别 14 色与地区 10 色说明。
- 无障碍：地图节点有 44px 可聚焦覆盖层（Tab 可达、聚焦环、hover 提示）、年份变更写入 `aria-live`、时间轴 slider、正文字号提升；`prefers-reduced-motion` 关闭自动播放、脉冲环、旋转印章与行进光点。
- 手机：地图基准比例 +8%，地区条右侧渐隐，抽屉内字号提升，390×844 无横向溢出。
