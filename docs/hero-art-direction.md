# 英雄插画风格指南 / Hero Art Direction

Version 1.0 · 2026-11-06. Applies to Tier A hero scenes (`js/hero-scenes.js`) and the print baseline for Tier C.

## 1. 目标

让 12 → 30 个英雄场景**各自独立、又能被认出是同一个世界**：

- 版画 / 羊皮纸 / 朱砂 / 赭金 / 墨褐，不是游戏 CG、不是照片、不是霓虹。
- 每个场景 3–5 层、一个视觉焦点、一个前景框。
- 时代与地域一眼可辨；不编造史实。
- 手机端可运行；16 秒内结束并清理。

## 2. 画布与坐标

- 舞台虚拟坐标：**宽 100 单位**，`x ∈ [-50, 50]`，地面 `y = 0`，天空向上为负。
- 人物基准高度：**4 单位**（约 26–30px @ 660px 画布）。
- 建筑、树木、船体按同一尺度体系；不因“看起来小”而放大人物。
- 地图徽章使用另一套坐标（约 150×110 单位），不套用舞台比例。

## 3. 色板

| 角色 | 色值 | 用法 |
|---|---|---|
| 纸 | `#f4e7c9` / `#ead7b2` | 天空、底色、留白 |
| 浅赭 | `#d8b266` | 受光面、沙、麦 |
| 中赭 | `#b98a3e` | 建筑、土地、木材 |
| 深褐 | `#7a5434` | 阴影、船体、屋顶 |
| 墨 | `#43301d` | 主轮廓、人物、刻线 |
| 朱砂 | `#a8402c` | 旗帜、印章、焦点强调 |
| 冷色 | `#4f6f78` | 水、夜、金属（少量） |

规则：

- 每场景最多 **2 个强调色**（通常朱砂 + 冷色或赭金）。
- 不用纯黑 `#000`；不用纯白大面积；不用高饱和霓虹。
- 远近用明度与饱和度拉开：远景浅、低饱和；近景深、高对比。

## 4. 明暗结构

每个场景必须能读出**三个价值带**：

1. **亮**：天空、受光墙面、水面高光。
2. **中**：建筑主体、山体、船体、人物衣物。
3. **暗**：前景框、屋檐下、船底、树冠、阴影侧。

规则：

- 光源统一为**左上**；投影落在右下。
- 主要物体至少有一个暗面或投影；不允许“全平涂”。
- 前景 20–30% 必须有暗色锚点（树、船、墙、地形），否则画面会浮。
- 暗部用深褐/墨褐，不用纯黑大块。

## 5. 线质

| 层级 | 线宽（舞台单位） | 用途 |
|---|---:|---|
| 主轮廓 | 0.55–0.75 | 建筑外轮廓、船体、主要地形、前景树 |
| 结构线 | 0.30–0.45 | 门窗、屋顶、甲板、桅杆、桥面 |
| 细节线 | 0.12–0.25 | 瓦线、砖缝、木纹、绳索、水纹 |
| 刻线 | 0.10–0.18 | 排线、交叉排线、点刻 |

规则：

- 主轮廓明显粗于细节线；不要所有线一样细。
- 暗面用**排线/交叉排线**，不是纯色块。
- 受光面可留白或只画一条高光边。
- 线条允许轻微不规则，但不能抖动成噪点。

## 6. 材质语言

每个场景至少使用 **3 种**：

- 建筑：砖缝、石砌、瓦线、木纹、白灰墙、柱影。
- 地面：沙纹、草簇、石砾、田垄、车辙。
- 水面：横向波纹、反光、浪脊、交叉排线。
- 船体：船板线、龙骨、撞角、桨孔、炮门、舷窗。
- 植被：树冠团块、棕榈叶、芦苇、苔点。
- 纸张/织物：纤维线、折痕、卷轴、经幡。
- 金属：金饰、青铜、铁甲（少量高光，不做镜面）。

禁止：照片纹理直接贴图、噪点过密导致脏、材质与时代不符（如唐代场景出现现代砖）。

## 7. 构图

### 必须

- 一个主焦点（建筑、船、人物组、云柱），占画面 1/4–1/3。
- 一个前景框（树、船首、墙、地形、拱门），建立深度。
- 三层景深：远（天空/山/海平线）、中（主建筑/地貌）、近（人物/道具/前景）。
- 地平线高度按主题选择：海战可低，城市可中，纪念建筑可高；不要每张都同一高度。
- 除泰姬陵等纪念建筑外，避免正中对称；用对角线、三分法或偏心焦点。

### 禁止

- 主体贴边、被裁切到不可读。
- 一排完全相同的房屋/树木/人物（重复节奏）。
- 人物排成一条直线或挤成“人团”。
- 画面上下各一半空白、没有前景框。
- 同一批场景共用同一轮廓（模板换色）。

## 8. 人物与动物

- 人物 4 单位高；远景 2–3 单位；前景 5–6 单位。
- 至少 3 种姿态：行走、站立、持物/劳作/招手；不要全是同一剪影。
- 群体要有前后错落和大小变化；不要等距排排站。
- 人物脚下必须有接触阴影（已有 `person()` 默认）。
- 动物（马、骆驼、牛、狼）按真实比例；腿、颈、头、尾可辨；不画成四腿方块。
- 船工、骑兵、僧侣、工匠的服饰/道具要符合时代与地域。

## 9. 动效与粒子

- 动画是写意版画：慢速、轻微、可循环 16 秒。
- 允许：旗帜/帆/衣角摆动、水波、烟、尘、雪、灰、光晕、鸟。
- 每帧粒子建议 <80；人物 <30；船只 <6。
- 不无限循环：地图剧场 16 秒清理；史志舞台由用户关闭。
- 不做快速闪烁、频闪、爆炸白屏（1945 场景尤其注意）。

## 10. 文字与标签

- 画面内不写大段文字；标题由 UI 负责。
- 地图剧场只画一个事件标题 chip；不与地图年份徽章重复。
- 年份、地名、参与方必须与事件数据一致；不编造。
- 多语言时标题跟随 UI 语言；画面内避免依赖文字表达。

## 11. 验收 rubric（硬门槛 + 1–5 分）

### 硬门槛（任一不满足即退回）

- 5 层：远景、中景、主体、光效/粒子、标签。
- 3 个价值带可读。
- 8 个材质区、3 种刻线技法。
- 与同批场景轮廓不重复（人工 A/B）。
- 3–5 条可核对史实细节。
- 16 秒清理、无重复标签、徽章 ≤64px、船头正方向、战斗单位 ≤16。
- 中端机 60fps、低端 ≥30fps；单帧 <16ms。

### 评分（1–5）

| 维度 | 1 | 3 | 5 |
|---|---|---|---|
| 构图/焦点 | 无焦点、平铺 | 有焦点但前景弱 | 焦点明确、三层景深、前景框 |
| 明暗层次 | 全平涂 | 有暗面但不系统 | 三价值带、投影/暗面统一 |
| 版画质感 | 纯色块 | 有线条/少量排线 | 主轮廓/结构线/细节线/刻线层级清楚 |
| 时代地域 | 泛化 | 有 1–2 个特征 | 建筑/服饰/器械/地貌均准确且可辨 |
| 系列一致 | 像另一套作品 | 色板接近 | 同一印版语言、同一尺度、同一光向 |
| 手机可读 | 糊/卡 | 可看但拥挤 | 小屏主体清楚、帧率达标 |

目标：Tier A 平均 ≥4.5；单场景不低于 4。

## 12. 实现指南

1. 在 `js/hero-scenes.js` 的 `SCENES` 注册 `{ stage, map, title }`。
2. `stage(ctx, top, t)`：使用第 2 节坐标；先画天空/远景，再中景、主体、光效。
3. `map(ctx, t)`：使用地图徽章坐标；控制在 150×110 单位内，避免硬边（`mapWrap` 会羽化）。
4. 复用共享笔刷：`person / horse / camel / ox / wolf / junk / caravel / trireme / cnGate / pagoda / domeTomb / cathedral / palaceFacade / lunarModule / astronaut / radio / paperVat / paperRack / acropolis / palm / mushroomCloud / ridge / hatch`。
5. 不新增全局混合模式；印版基调由 `finishPlate` 统一处理（source-over）。
6. 每次新增场景，更新 `docs/hero-illustrations.md` 的场景表与验收记录。

## 13. 评审清单（每场景打勾）

- [ ] 三价值带可读，暗部非纯黑
- [ ] 主轮廓/结构线/细节线层级清楚
- [ ] ≥3 种材质技法，≥8 个材质区
- [ ] 人物姿态 ≥3 种，群体错落
- [ ] 前景框 + 三层景深
- [ ] 3–5 条史实细节可核对
- [ ] 16 秒清理、无重复标签
- [ ] 390×844 可读、无溢出
- [ ] 中端机 60fps / 低端 ≥30fps
- [ ] 与同批场景轮廓不重复
