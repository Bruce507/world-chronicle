# 人工验证清单 / Manual verification checklist

Date 2026-11-08。本文件只定义**怎么做**，不声称已经做过。没有真机或人工听读时，任何一项都不得写成"已验证"。

## 1. VoiceOver（macOS，30 分钟）

1. 系统设置 → 辅助功能 → VoiceOver → 开启（⌘F5）。
2. Safari 打开 `https://bruce507.github.io/world-chronicle/?year=1937`。
3. 用 `VO + →` 顺序走查，记录读屏顺序：跳转链 → 顶栏 → 地图节点 → 面板 → 时间轴。
4. 检查：
   - 时间轴滑块读作"时间轴年份，1937，最小值 −12000，最大值 2026"；
   - 年份变化时 `#a11y-live` 播报"公元 1938 年 · 世界大战"；
   - 剧场开始/暂停/结束分别播报；
   - 事件列表用 `VO + 方向键` 或 Tab 进入后，**方向键在行间移动**，回车打开；
   - 时代下拉可读出"时代：选择后放大该时代"；
   - 关闭事件面板后焦点回到触发点。
5. 记录任何"读不出名称 / 顺序跳错 / 焦点丢失"的步骤与截图。

## 2. NVDA（Windows，20 分钟）

1. 安装 NVDA，Chrome 打开同一 URL。
2. 用 `H` 跳标题、`D` 跳地标、`F` 跳表单，核对地标顺序。
3. 重点听：滑块 valuetext、事件行 roving tabindex、`aria-live` 播报、下拉名称。
4. 记录朗读文本与预期不一致之处。

## 3. iPhone / iOS Safari（15 分钟）

1. Safari 打开线上站，分享 → 添加到主屏幕。
2. 从主屏幕启动，确认全屏与安全区。
3. 飞行模式后冷启动：已访问页面应可读，未访问事件应显示"摘要"而非空白。
4. 分享一张事件卡片，确认文件保存/分享面板可用。
5. 记录机型、iOS 版本、是否成功；不成功时记录页面提示。

## 4. 低端 Android（15 分钟）

1. Chrome 打开线上站，记录冷启动到可交互的秒数（秒表）。
2. 拖动时间轴、打开 3 个事件与剧场，观察掉帧/发热。
3. Chrome DevTools 远程调试记录 JS 堆与画布内存（如可用）。
4. 记录机型、Android 版本、内存。

## 5. 母语审校（ES/FR/AR）

- 每语言至少 1 名母语者，抽 20 条史志 + 20 个地图标签。
- 只看译文，不看英文原文；标出"读不懂 / 术语不对 / 语气不对"。
- 修改前不得把长文翻译标成"已审校"。

## 6. 盲测（6 人）

- 材料：`docs/blind-test-2026-11/`（未标注的家族图 + 独立 key）。
- 流程与通过线见该目录 `README.md`。
- 评审不得是项目参与者；参与者只能算内部走查。

## 7. 记录去向

结果写入 `docs/manual-results-<date>.md`，逐项标注 `通过 / 失败 / 未执行`，并附设备与版本。未执行项保持"未验证"，不进入发布结论。
