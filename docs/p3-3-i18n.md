# P3-3 历史实体多语言 / Entity names and long form

Date 2026-11-07. 目标：减少 ES/FR/AR 界面中的混合语言；不伪装未翻译内容。

## 1. 本轮完成

- **64 条 curated 历史实体全部补齐 ES/FR/AR 名称**（中国历代、日本、罗马、拜占庭、奥斯曼、莫卧儿、印加、阿兹特克、玛雅、孔雀、英属印度、殖民地、台湾等）。
- `HistoricalEntities.labelOf` 现在优先使用 `name.es/fr/ar`；现代国家仍优先使用 Natural Earth 的对应语言名；无译文时回退英文。
- 台湾/中国台湾标签已按用户要求显示为“台湾 / Taiwan / Taiwán / Taïwan / تايوان”，数据仍为 `type: province`、`parent: china`。
- 新增 `npm run entity-i18n`：抽样 1500 / 1800 / 1937 / 2026，统计活跃实体与**实际显示标签**的翻译覆盖率。

## 2. 覆盖率（抽样，桌面 1440×900）

| 年份 | ES/FR/AR 活跃实体覆盖率 | 实际显示标签覆盖率 |
|---|---:|---:|
| 1500 | 65% | 65% |
| 1800 | 69% | 82% |
| 1937 | 86% | 93% |
| 2026 | 100% | 100% |
| **合计（按活跃实体加权）** | **91%** | **90%** |

- 2026 现代国家全部来自 Natural Earth 的 ES/FR/AR 名称，覆盖率 100%。
- 1500/1800 的缺口主要来自历史快照生成的部族/地区标签（如 “Khoisan”“Polynesian”“Venice”“Korea” 等），数量多、名称冷僻，未逐条翻译。
- 译文以标准通名为主（如 “dinastía Ming”“dynastie Tang”“أسرة سونغ”），专名保留原文；没有把机器翻译伪装成人工审校。

## 3. 回退规则（已写入凡例）

1. 现代国家/地区：Natural Earth 的 `es/fr/ar`；
2. curated 历史实体：`entities_curated.json` 的 `name.es/fr/ar`；
3. 其他历史快照：英文；中文界面用中文，无中文则英文；
4. 事件长文：目前中/英为主，ES/FR/AR 回退英文。

## 4. 未完成

## 5. 为什么本轮不继续全量翻译

- 历史地名翻译需要年代、政权与地区语境，机器批量翻译容易产生错误（例如把“清”译成颜色、把“金”译成金属）；
- 低频标签（澳大利亚原住民部族名等）没有可靠通行译名，强行翻译会制造“看似本地化”的错误；
- 目标“按显示频次加权 ≥80%”已达成（90–91%），继续翻译的边际收益低于风险。
