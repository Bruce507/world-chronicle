## 一、设计师视角

### D8 · RTL 下的时间轴控件挤成一条、提示文字被 bidi 拆散 · P1 · **已修复**

- 证据：`desktop-rtl.jpg`（修复前）。右端依次是"تكبير إلى 1750–2026 / 刷选 / 1× / اليوم"，四个控件没有分组；轴底部提示的方向键在阿拉伯文里被 bidi 翻转。
- 修复：工具栏拆成"视图（聚焦近现代 / 刷选）"与"播放（1× / 今天）"两组，用逻辑边框（`border-inline-start`）分隔，窄屏自动去掉分隔；提示条在 RTL 下固定 `dir="ltr"`，保留阿语词序而不镜像按键；刷选按钮的语言在切换语言与启动时都会刷新（此前启动即为阿语时不会）。
- 验证：`desktop-rtl.jpg`（修复后）与 390×844 截图 `mobile-timeline.jpg`；`scrollWidth == innerWidth`。

### D9 · Tier B 同家族高度同构，且有"家族套错" · P1（内容质量）

- 证据：`p3-2-tierb-contact.jpg` 与多样性数据——Hero 32 个平均两两差异 0.170，Tier B 45 个 0.107，其中 modern 政治 18 个仅 0.062、siege 16 个仅 0.063。
- 18 个现代政治变体的差异几乎只有旗帜颜色与天空；16 个 siege 变体共用"城墙 + 帐篷 + 旗"。
- 具体错误：淞沪（1937）、台儿庄（1938）、武汉（1938）、百团（1940）使用中世纪城墙——已在收口时修复：新增 `urban-war` 家族，4 个事件迁入（见 `p3-2-scenes.md` §7）。全量差异由 0.107 升到 0.121，新家族内部 0.120。
- **仍未解决**：modern 政治家族内部差异只有 0.060（20 个变体）；这是"同构"而非"套错"，需要新构图，留待 P4 Gate 3。

### D10 · 事件弹窗右栏中段留白过大 · P2 · **已修复**

- 证据：`desktop-theatre.jpg`（修复前）。右栏在"联动 2 地"标签与"同一时刻的世界"之间约 150px 空白。
- 修复：`.ev-contemp` 不再用 `margin-top:auto` 顶到底部，改为紧跟正文（22px）；`.ev-nav` 用 `margin-top:auto` 贴底。空白从"内容中间"移到"内容与操作条之间"，读起来是呼吸而不是断裂；390×844 下间距收到 14px。
- 验证：`desktop-theatre.jpg`（修复后）。

### D11 · 国家面板的"分享卡片"按钮孤立 · P2 · **已修复**

- 证据：`desktop-country.jpg`（修复前）。按钮单独一行，位于国家标签行与"此处此时"之间。
- 修复：新增 `.panel-topbar`，返回在左、分享在右，同一行；路线面板同样处理。
- 验证：`desktop-share-toast.jpg`；smoke 新增「country and route tools sit in one top bar」。

### D12 · 多语言下地图标签仍混排 · P2 · **已说明（UI 层）**

- 证据：`desktop-rtl.jpg` 上 "U S S R"、"French West Africa" 与阿拉伯语标签同屏。
- 说明：这些是历史快照原始英文名，没有可用阿语/西语译名（见 `p3-3-i18n.md` 的回退规则）。不是 bug，但视觉断层明显。
- 处理：不降低这些标签的不透明度（会伤对比度），改为**在图层弹层里就地说明**——"没有译文的历史地名保留原文"，只在 ES/FR/AR 显示；凡例原有的长说明保留。
- 验证：`desktop-layers-lang.jpg`。数据侧继续按 `p3-3-i18n.md` 的清单补译。

### D13 · 时间轴最底部的刻度与范围文字过小 · P3

- 证据：`desktop-1937.jpg` 底部；"范围 前12000—2026 · 步进 1 年"与轴下刻度均为 8–10px 级。
- 说明：D7 已把正文/图例/地图标签提到 10–11px，时间轴刻度仍是例外；它是辅助信息，但也是"现在看的是哪一段"的唯一提示。

### D14 · 收藏空状态的"导入备份"没有分组 · P3

- 证据：`desktop-favourites.jpg`。空状态说明文字后直接跟一个描边按钮，没有小标题。
- 建议：加一行"从备份恢复"分组标题，或在空状态里写成"从 JSON 备份恢复收藏 →"的链接式按钮。

### D15 · 顶栏层级：工具行与地区行视觉重量接近 · P3

- 证据：`desktop-1937.jpg`。地区条（亚洲/欧洲/…）与工具按钮（图层/凡例/收藏）字号、边框接近，用户需要读文字才知道哪行是导航、哪行是设置。

## 二、使用者视角

### U10 · 核心脚本加载失败时是"空白地图 + 首访引导" · P1（本轮已缓解）

- 证据：本轮截图过程中两次出现（`desktop-route` 第一次拍摄），页面停在 3000 BCE、地图全空、引导层浮在上面，没有任何错误说明。
- 本轮修复：boot 检测不到 `AtlasMap` 时在面板里写明"地图脚本未能载入，请检查网络后刷新"。
- 同时修复：启动失败时不再弹出首次引导，提示不会被盖住。

### U11 · 深链打开事件会改年份，且 URL 不同步 · P1 · **已修复**

- 证据：访问 `?year=1937&event=hiroshima` 后 `state.year=1945`，但地址栏仍是 `year=1937`；按"返回时代"后年份停在 1945。
- 修复：打开事件时记住来源年份（仅用户主动打开、且年份确实变化时），"返回时代"恢复该年份并清空记录；深链应用结束后补一次 `replaceState`，地址栏与屏幕一致。
- 验证：同一 URL 打开后 `state.year=1945`、地址栏 `?year=1945&event=hiroshima`；点"返回时代"后 `state.year=1937`、地址栏 `?year=1937`、事件关闭。

### U12 · 屏幕阅读器/翻译视角下的首访引导曾经全英文 · P1（本轮已修）

- 证据：`js/i18n_extra.js` 缺 21 个键，其中 11 个属于首访引导；ES/FR/AR 用户第一次进入时看到的是英文三步说明。
- 本轮已补全 21 个键 × 3 语言，并把"ahead/Open sea/NOW/born/nodes/Pause"等 10 处 zh-EN 专用片段接入五语 `L()`。

### U13 · 清空收藏没有确认或撤销 · P2 · **已修复**

- 证据：`renderFavoritesPanel` 的"清空收藏"直接 `favorites = []`，只有 toast。
- 修复：改为两步——第一次点"清空收藏"展开确认条"确定清空全部 N 条收藏？此操作不可撤销。[清空][取消]"；取消回到列表，确认才清空。打开收藏面板或离开时自动复位。
- 验证：smoke「clearing favourites asks first and can be cancelled」（arm → cancel → confirm）；`desktop-favourites-confirm.jpg`。

### U14 · 分享卡片的落点不明确 · P2 · **已修复**

- 证据：桌面 Chrome 上 `navigator.canShare({files})` 为 true，会走系统分享面板；不支持的浏览器直接下载文件，仅一句 toast。
- 修复：下载路径的 toast 改为"已保存 world-chronicle-xxx.png [打开]"——toast 现在支持一个动作按钮（9 秒后消失）；blob URL 保留 60 秒供"打开"使用。系统分享面板的路径不变。
- 验证：`desktop-share-toast.jpg`（屏蔽 `navigator.canShare` 后走下载路径）。

### U15 · 离线打开未访问事件时"降级但不说明" · P2 · **已修复**

- 证据：断网后打开 `battle-of-mohacs`，面板正常显示标题、时间、地点、摘要与"简要条目"标记，但没有说明长文与剧场需要联网。
- 修复：面板顶部新增离线说明条（`#panel-offline`，`role="status"`）："离线：摘要与已缓存内容可用；长文、未访问事件与剧场需要联网"，联网即隐藏；底部全局状态条保留。
- 验证：smoke「offline status bar and panel note appear while offline」；`mobile-offline-panel.jpg`。

### U16 · 手机 2026 首屏没有事件列表入口 · P3

- 证据：`mobile-2026.jpg`。面板默认收起，屏幕上只有地图与时间轴；"‹ 此刻世界"是唯一入口且字号小。
- 说明：这是为地图留空间的刻意取舍，但新用户不知道还能点它。

### U17 · 手机搜索无清除按钮 · P3

- 证据：搜索输入框 `type="search"` 在 iOS 上有系统清除，Android/桌面没有；结果下拉盖住地图上半部。

### U18 · iOS 安装提示只有一次，且不解释后果 · P3

- 证据：`mobile-ios-hint.jpg`。提示只说明操作路径，未说明"安装后可离线""iOS 清理存储可能清掉缓存"。
- 说明：一次性的轻提示是合理取舍，但文档必须写清限制（见 `p3-6-product.md` §8）。

## 三、做对了的地方（避免只列问题）

1. **剧场质量**：`desktop-theatre.jpg` 的阿波罗十一号是全站最强的一屏——构图、配色、文字层级都对；16 秒静态末帧让阅读不被清屏打断。
2. **离线状态条与安装/更新条**放在时间轴上方，不遮挡地图，390×844 无溢出（`mobile-offline.jpg`）。
3. **RTL 是真镜像**：面板到左侧、品牌到右侧、地图标签按阿语排版，不是简单 `direction: rtl` 的错位（`desktop-rtl.jpg`）。
4. **收藏导出/导入**在空列表时也能导入，换浏览器恢复的路径是通的（smoke 覆盖回环）。
5. **地图标签对比度**在 1937 密集区仍可读，抽样最低 5.47:1。
