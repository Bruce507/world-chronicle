## 3. 政治敏感事件

关键词扫描命中 61 条（南京、大屠杀、核爆、分治、殖民、奴隶、战争、饥荒等）。本轮逐条阅读了 20 条高风险条目：南京大屠杀、奥斯维辛、广岛、长崎、印巴分治、海地革命、印度洋海啸、COVID-19、俄乌战争、九一一、鸦片战争、淞沪/台儿庄/武汉/百团、蒙古攻陷巴格达、阿兹特克覆灭等。

处理原则：

- 伤亡数字只给区间并注明争议（南京“数万到三十万以上”、广岛“约7万–14万”、长崎“约3.5万–7万”）；
- 不把有争议的学术判断写成定论；
- 敏感事件保持纪念性、非煽动叙述；
- 台湾表述：数据为省级实体、非现代国家；界面“台湾/中国台湾”，不以“省”作为标签前缀；
- 发现并修正 2 处中英混排：`founding-of-rome` 的 “contemporaneous”、`indian-ocean-tsunami` 的 “modern 史上”。

未做：独立史学审稿；61 条中其余 41 条只做了关键词与措辞扫描。

## 4. 标签位置与碰撞

在 1440×900 与 390×844 下抽样 1500 / 1800 / 1914 / 1937 / 2026：

| 年份 | 桌面显示/跳过 | 手机显示/跳过 | 可见重叠 | 边缘裁切 |
|---|---:|---:|---:|---:|
| 1500 | 18 / 2 | 13 / 7 | 0 | 0 |
| 1800 | 23 / 5 | 19 / 9 | 0 | 0 |
| 1914 | 43 / 22 | 22 / 43 | 0 | 0 |
| 1937 | 46 / 25 | 22 / 49 | 0 | 0 |
| 2026 | 46 / 156 | 22 / 178 | 0 | 0 |

- 可见重叠为 0（碰撞检测会丢弃放不下的标签）；边缘裁切为 0（20px/14px 内缩）。
- “跳过”不是错误，而是密度控制：2026 有 196 个现代条目竞争标签位，桌面上限 78、手机 44；实际显示 46/22 是因为视口内可用标签位更少。
- 风险：1914/1937 的欧洲与东亚密集区仍有 22–49 个标签被丢弃；用户可能觉得“少了一个国家”。P3-7 续可用缩放分层/优先级和手动位置修正改善，但不建议简单提高上限（会重新引入重叠）。
- 台湾标签位置 (23.65, 120.87) 在 2026 正常显示，未被裁切。
