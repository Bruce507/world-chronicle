# WebKit 回归与无障碍树走查 / WebKit regression and accessibility tree

Date 2026-11-08。范围：Playwright **WebKit 27.2**（Safari 引擎的自动化构建）关键路径回归 + Chromium 计算无障碍树（CDP）走查 + 400% 缩放与 forced-colors 组合。

**不是真机验证**：没有 iPhone/Safari 真机、没有 VoiceOver/NVDA 人工听读。本文所有"通过"指脚本断言通过，不能写成"NVDA 已验证 / iOS 已验证"。

## 1. 怎么跑

```bash
npx playwright install webkit          # 一次性
python3 -m http.server 8001 --directory .
npm run webkit                         # 15 项
npm run a11y                           # 36 项（原 21 + AX 树 9 + 400% 3 + 小字对比度 2 + roving 1）
```

WebKit 套件与 Chrome smoke 的关键路径一致，但**不改 Chrome 套件的语义**；断言单独写，避免把 Safari 的差异误当成产品回归。

### Safari 专属问题

- **没有发现 Safari 专属的脚本或布局故障**。上面 15 项在 WebKit 与 Chrome 上行为一致；字体、面板宽度、时间轴刻度、剧场末帧截图对比一致。
- 回归过程中发现的 1 个问题**不是 Safari 专属**，Chrome 同样复现，已修：时代面板自动滚到「此刻」分隔线时，粘性分类行盖住了分隔线标签（固定 76px 偏移不够，分类行在桌面折成两行高 74px）。现按分类行实测高度 + 22px 计算偏移（`js/app.js`），两种引擎下标签都完整可见。

## 3. 无障碍树走查（Chromium 计算树）

Playwright 1.64 移除了 `page.accessibility`；改用 CDP `Accessibility.getFullAXTree` 读取**浏览器计算后的树**（1195 个节点，按树序展开），不是 DOM 源码顺序。

| 检查 | 实测 | 结论 |
|---|---|---|
| 地标顺序 | skip link (1) → banner (8) → main (65) → complementary (105) → contentinfo (703) | ✓ 读屏顺序为 顶栏 → 地图/面板 → 时间轴 |
| 跳转链 | 第一个可交互节点是「跳到详情面板」 | ✓ 先于 banner |
| 可交互节点名称 | button / link / slider / searchbox / combobox / checkbox 等全部有名称 | ✓ 0 个无名节点 |
| 年份滑块 | 名称「时间轴年份」，min −12000，max 2026，value 1937 | ✓ |
| 面板标题 | 「世界大战」「时代节点 · 62」「并立文明」 | ✓ 标题层级可读 |
| 地图节点覆盖层 | 7 个按钮全部以 `事件名 · 年份` 命名，且在 AX 树中就是按钮 | ✓ |
| 年份播报 | `#a11y-live`（`aria-live=polite`、`atomic=true`）：设到 1938 后文本变为「公元 1938 年 · 世界大战」 | ✓ |
| 剧场播报 | `#theatre-live`（polite）：开始/暂停文本变化 | ✓（原有检查） |

**CDP 的一个协议限制**：即使 `aria-valuetext` 已设置，Chromium 的 AX 树序列化里 `valuetext` 仍为空字符串（用最小页面复现，与本站无关）。因此人读年份在 DOM 属性断言（`aria-valuetext="公元 1937 年 · 世界大战"`），AX 树只断言名称/范围/当前值。这不影响读屏软件读取 `aria-valuetext`，但本文不把它写成"读屏已验证"。

### 走查中发现并修复

| 问题 | 证据 | 修复 |
|---|---|---|
| 键盘到时间轴要按 **123 次 Tab**：地图节点层（当前 7 个）+ 62 条时代事件行 + 顶栏 14 个控件，以及面板与时间轴自身的按钮都在滑块之前 | 脚本逐步 Tab 计数 | 新增第二个跳转链「跳到时间轴」；随后把事件行、政权 chip、地区 chip、地图节点改为 **roving tabindex**，实测到时间轴降到 **39 次 Tab** |
| `#a11y-nodes` 是带 `aria-label` 的无角色 `div` | axe 400%：`aria-prohibited-attr` | 加 `role="group"` |
| 400% 下触控目标不足 24×24：半屏拖柄 320×22、年份 ± 按钮 22×22 | axe 400%：`target-size` | 拖柄 22→24px、步进按钮 22→24px；axe 复跑 0 违规 |

### 仍未解决（明确保留）

- **Tab 路径已大幅缩短**：事件列表、政权 chip、地区 chip 与地图节点各只保留 1 个 Tab 停靠点，方向键在组内移动，且不再触发行年变化（`stopPropagation`）。剩余 39 次主要来自顶栏、分类 chip、面板工具与时间轴控件，本轮未再压缩。
- **NVDA / VoiceOver 未实测**：以上是计算树与脚本断言，不是人工听读。

## 4. 400% 缩放与 forced-colors 组合

| 场景 | 结果 |
|---|---|
| 200% 缩放（720×450） | 无横向滚动；axe WCAG 2.2 A/AA 0 违规（原有） |
| 400% 缩放（320×256） | 无横向滚动（`scrollWidth = 320`）；面板横向溢出 0；时间轴与关闭按钮在视口内；axe **0 违规**（修复后） |
| 400% + forced-colors | 布局完整、时间轴可见、焦点轮廓保留（`solid:2px`） |
| forced-colors（1440×900） | 地图仍绘制、无溢出、焦点轮廓保留（原有） |

400% 是 WCAG 1.4.10 的 320px 等价宽度；320×**256** 高度下地图本体只剩一条窄带，这是"以地图为主界面"的固有限制——搜索、时间轴、面板仍可操作，没有横向滚动。

## 4.1 D7 小字收尾（与无障碍同批）

- `css/style.css` 中 **46 处** 7–9px 的 `font-size` 统一提到 **9.5px**：品牌副题、时代带日期、面板 kicker、事件元信息、史志标题、弹窗 kicker、收藏角标等。
- 两处容器随字号调整：收藏角标 13px → **15px**（9.5px 数字不挤），年份按钮补足 24px 命中区。
- 时代带的两级文字原来用 50%/62% 透明度，9.5px 下对比度只有 2.12:1；改为 `--muted`（5.57）与 `--ink-2`（7.24）。
- 新增两项**实际背景**对比度抽样（逐层合成 `background-color`，不是只比色板）：主视图 12 个选择器最差 **5.52:1**；事件弹窗 4 个选择器最差 **5.32:1**。均 ≥ 4.5。
- 手机上字号变大后 2026 半屏一度只剩 4 行；通过压缩行距（分区标题 4→2px、分类行 4/3→2/2px、分区上距 10→8px、面板头 6→4px）恢复 **5 行**，smoke 复跑通过。
