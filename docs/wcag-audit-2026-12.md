## 2. 本轮修复

- 颜色 token 加深，保证 `--muted`/`--gold`/`--verm` 在 `#e9e0cf` 纸色底上 ≥4.5：`#655c51` / `#7d5a20` / `#a83e28`。
- 新增跳过链接（“跳到详情面板 / Skip to panel”）；`#side-panel` 可接收焦点。
- 事件弹窗与凡例弹窗：打开时 `#app.inert = true`，Tab 在弹窗内循环；关闭时恢复焦点。
- 装饰性画布 `fx-canvas` / `tick-canvas` / `scene-canvas` 标记 `aria-hidden`。
- 修复自动播放事件会关闭正在阅读的事件弹窗：弹窗打开时暂停自动事件，自动事件不再关闭它。
- 修复首屏深链应用会重置用户已打开的事件；现在只在用户尚未导航时应用一次。

## 4. 未验证 / 后续

- **NVDA（Windows/Chrome）与 VoiceOver（macOS/Safari、iOS）完整走查**：未做。地图画布、弹窗、抽屉、迷你地图需要逐项听读。
- **200% / 400% 缩放与高对比模式**：未做。
- **地图标签对比度**：画布上的 rgba 文本无法用 DOM 工具测量；需逐年份抽样或改用更高的最低不透明度。
- **小目标**：面板关闭 28px、更多菜单 30px、图例形状 10px；WCAG 2.2 的 24px 最小目标基本满足，44px 仅地图节点。
- 真实屏幕阅读器可能对 `inert`、`role=application`（迷你地图）有不同行为，需要实测后调整。

## 6. 第二轮：axe-core、200% 缩放、强制色彩与画布标签对比度（2026-11-07）

`npm run a11y` 从 14 项扩展到 **20 项**，全部通过。

### 新增检查

| 检查 | 方法 | 结果 |
|---|---|---|
| WCAG 2.2 A/AA | axe-core 4.14（devDependency，注入页面执行，**不进入运行时**） | 主视图 **0 违规** |
| 200% 缩放 | 1440×900 窗口按 720×450 CSS px 复现 | 无横向滚动，时间轴与面板可用；axe **0 违规** |
| 强制色彩（Windows 高对比） | `forcedColors: active` 模拟 | 布局完整、地图有像素绘制、焦点轮廓保留（2px solid） |
| 画布历史标签对比度 | 采样标签下方真实地图颜色，按代码中的光晕/字色 alpha 合成后计算 | 16 个样本最低 **5.47:1** |
| 画布现代国名对比度 | 打开"现代国名"图层后采样 | 14 个样本最低 **7.74:1** |

### 本轮修掉的问题

- **文化类标签对比度不足**：实体层对 `type: "culture"` 使用 `rgba(88,72,54,0.7)`，按上述方法合成只有约 **3.8:1**，低于 AA 的小字要求。改为 `0.84` 后为 5.0:1 以上；现代国名（0.74）与其他政权（0.86）本就达标。
- **面板标题的默认蓝色焦点框**：深链打开事件后脚本聚焦 `#panel-title`，Chrome 画的是 UA 默认蓝框；改为站点朱红焦点环。

### 仍未完成（不要当作已通过）

- **NVDA / VoiceOver 实测未做**：本机没有 Windows/NVDA 环境；VoiceOver 需要人工听读，不能用脚本替代。凡涉及"朗读顺序、播报内容、画布节点听读"的结论仍为**未验证**。
- 400% 缩放未测（1.4.10 对地图类内容有例外，但仍需人工确认重排）。
- 对比度为"合成模型 + 背景采样"，不是逐字形像素测量；字重、抗锯齿会让实测略低。
- 剧场状态（开始/暂停/结束）仍没有独立 `aria-live` 播报。
- 面板关闭按钮 28px、更多菜单 30px 仍小于 44px（满足 WCAG 2.2 的 24px 最小目标，不满足 AAA 建议值）。
