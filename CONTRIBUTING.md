# Contributing to 寰宇时序 · World Chronicle

Thank you for helping the atlas grow. The project is deliberately **static and dependency-free**: data lives in plain JSON, the runtime bundle is generated, and the map is drawn with Canvas.

## Quick start

```bash
npm run validate   # check every JSON source
npm run build      # regenerate js/data_bundle.js
npm run serve      # python3 -m http.server 8000
```

For a full rebuild from the external sources:

```bash
python3 scripts/build-historical.py /path/to/historical-basemaps/geojson
python3 scripts/build-world-50m.py /path/to/countries-50m.json
python3 scripts/enrich-world-i18n.py /path/to/countries.json
python3 scripts/build-state-changes.py
python3 scripts/build-coverage-events.py
node scripts/build-data.mjs
python3 scripts/build-chronicles.py
# optional: translate new events (network required)
python3 scripts/translate-events.py
```

The app only needs `js/data_bundle.js` at runtime; regenerate it whenever `data/events.json`, `data/polities.json`, `data/theatre.json`, `data/event_details.json`, `data/event_groups.json`, `data/regions.json` or `data/meta.json` change.

Additional data layers:

- `data/event_details.json` — structured background / course / outcome / actors / sources / verification per event. Brief entries are allowed and are labelled “简要条目” in the UI; do not invent missing background.
- `data/event_groups.json` — event chains and same-place/same-year groups (e.g. `japan-1945`). Country clicks and timeline stops resolve groups through the same trigger.
- `data/historical_entities.json` — generated historical label layer (snapshots + modern state births + curated entities). Rebuild with `node scripts/build-historical-entities.mjs`; edit `data/entities_curated.json` for China, Japan, Australia and other key regions.
- `data/regions.json` — top region navigator cameras. `bbox` is `[west, south, east, north]`.
- `data/name_gloss.json` — Chinese display names for historical labels; add entries here when a new snapshot polity should appear in Chinese mode.
- `data/scene_variants.json` — explicit event-to-visual-family overrides. Families live in `js/scenes.js` and `js/theatre.js` (founding, cavalry, naval, craft, monument, revolution).
- `docs/major-events.md` and `docs/coverage-matrix.md` — Phase 0 inventory/coverage reports; regenerate with `node scripts/build-reports.mjs`.

Run `node scripts/build-historical-entities.mjs` whenever curated entities or snapshots change, then `node scripts/build-data.mjs`.

## Add a historical event

Edit `data/events.json` and append an object:

```json
{
  "y": 1453,
  "lat": 41.01,
  "lon": 28.98,
  "c": "TR",
  "rg": "eu",
  "k": "war",
  "s": "siege",
  "f": 1,
  "t": ["君士坦丁堡陷落", "Fall of Constantinople"],
  "d": [
    "奥斯曼苏丹以巨炮轰塌千年城墙，拜占庭帝国终结。",
    "Ottoman siege guns breach the thousand-year walls, ending Byzantium."
  ],
  "link": [[41.9, 12.5], [45.46, 9.19]]
}
```

| Field | Meaning |
| --- | --- |
| `y` | Year; negative = BCE. No year zero. |
| `lat`, `lon` | Decimal coordinates. |
| `c` | Modern ISO2 code (optional fallback for country lookup). |
| `rg` | `af` `me` `eu` `sa` `ea` `sea` `ca` `na` `la` `oc` |
| `k` | `hunt` `agri` `city` `temple` `war` `trade` `politics` `culture` `religion` `science` `disaster` `exploration` `industry` `digital` |
| `s` | Scene id, one of `meta.json` → `scenes`: `hunt` `agri` `march` `pilgrim` `city` `temple` `chariot` `phalanx` `siege` `cavalry` `naval` `camel` `ship` `cannon` `musket` `revolution` `industry` `trench` `air` `atomic` `rocket` `digital` `protest` `plague` `disaster` |
| `t` | `[Chinese, English]` title. Keep both. |
| `d` | `[Chinese, English]` 1–2 sentence description. |
| `link` | Optional `[lat, lon]` points; used for global linkage arcs and map-theatre routes. |
| `f` | `1` for a featured node (larger marker, rotating seal, arcs). |
| `v` | Optional monument variant: `pyramid` `stones` `columns` `dome` `stupa` `towers` `pillars` `moai`. |
| `tx`, `dx` | Optional object `{ "es": "...", "fr": "...", "ar": "..." }` for translated titles/descriptions. When absent, non-Chinese readers see the English text. |
| `gen` | Leave absent for hand-written nodes. `"coverage"` entries are regenerated by `scripts/build-coverage-events.py`. |

Guidelines:

- Prefer **specific, verifiable** events over vague period descriptions.
- Give each event a place that can be anchored on the map; avoid ocean coordinates unless the event is maritime.
- The atlas is a curated, schematic overview. Do not claim precise borders in the text.
- Names: use the common scholarly name; dates: mainstream consensus; add a short bilingual note if a date is contested.
- Keep the Chinese and English descriptions semantically aligned.

## Add a map-theatre script

`data/theatre.json` drives the **on-map** dynamics. Keys are stable event slugs generated from the English title (e.g. `world-war-ii-begins`, `hiroshima`, `the-silk-road`).

```json
{
  "mode": "war",
  "zoom": 1.55,
  "center": [32, 62],
  "sides": [
    { "key": "axis", "name": ["轴心国", "Axis"], "color": "#a83e2c", "members": ["DE", "IT", "JP"] },
    { "key": "allies", "name": ["同盟国", "Allies"], "color": "#3f6278", "members": ["GB", "FR", "US", "RU", "CN"] }
  ],
  "fronts": [
    { "side": "axis", "label": ["东线", "Eastern Front"], "pts": [[55.7, 37.6], [51.8, 28], [47, 39], [45.5, 44.5]] }
  ],
  "battles": [
    { "lat": 48.7, "lon": 44.5, "name": ["斯大林格勒", "Stalingrad"], "side": "allies", "kind": "urban" }
  ],
  "routes": [
    { "mode": "ship", "side": "allies", "label": ["英吉利海峡", "English Channel"], "pts": [[51, -1.4], [49.6, -0.7]] }
  ],
  "end": { "lat": 52.52, "lon": 13.4, "year": 1945, "label": ["柏林", "Berlin"] }
}
```

`mode`: `war` `trade` `atomic` `disaster` `civic` `march` `pilgrim`.
Route modes: `camel` `ship` `march` `pilgrim` `air`.
Battle kinds: `land` `urban` `air` `naval` `artillery` `cavalry` `crowd` `outbreak` `wave` `port`.

Events without a theatre script get a sensible generated scenario from their coordinates, `link` points and scene type.

## Add a trade route

Add to `tradeRoutes` in `data/theatre.json`:

```json
{
  "id": "silk-road",
  "mode": "camel",
  "name": ["丝绸之路", "Silk Road"],
  "era": [-200, 1500],
  "countries": ["CN", "UZ", "IR", "TR", "IT"],
  "pts": [[34.27, 108.95], [40.14, 94.66], [35.0, 51.0], [41.9, 12.5]]
}
```

Routes are used when any country is clicked (the ones touching it animate) and by trade events.

## Add a state birth or dissolution

Edit `data/state_changes.json`:

```json
{
  "key": "SSD",
  "iso2": "SS",
  "iso3": "SSD",
  "name": { "zh": "南苏丹", "en": "South Sudan" },
  "year": 2011,
  "kind": "independence",
  "note": { "zh": "脱离苏丹独立", "en": "Independence from Sudan" },
  "lat": 7.87,
  "lon": 29.87
}
```

`births` power the green bloom on the map, the state-change list in the side panel, and the modern segment of each country chronicle. `dissolutions` use `{ year, name, lat, lon, note }` and render a grey broken ring.

State formation years in the dataset are **curated approximations**; note ambiguity in the text rather than pretending to certainty.

## Country chronicles

`data/country_chronicles.json` is generated from the simplified historical snapshots + events + state births:

```bash
python3 scripts/build-chronicles.py
```

Each country gets ruler-by-ruler segments (with an era, a modern segment and a birth year) and the event nodes inside each segment. Regenerate it whenever events or state changes change. If a snapshot at a country's label point has no polity, the segment is labelled “Local communities / 地方社群”.

## Add a scene or variant

- Add a scene function to `SCENES` in `js/scenes.js`, then register its name and bilingual label in `data/meta.json` under `scenes`.
- Add its miniature to `mini()` so map nodes animate.
- Building/scene variants already supported: `pyramid`, `stones`, `columns`, `dome`, `stupa`, `towers`, `pillars`, `moai`; ships choose junk/caravel/outrigger/steamship by region/year; cavalry chooses horse archer/knight/cataphract/dragoon.
- Scenes must be self-contained (Canvas 2D, no external assets), loop gracefully, and restore the canvas transform. `Scenes.mount` wraps them, but leaked `save()` calls can poison the frame.

## Translations

- Interface strings: `js/i18n_extra.js` (`es`, `fr`, `ar`); Chinese/English live in `js/app.js`.
- Era/region/category names: `window.DATA_I18N`.
- Country names: `data/world.geo.json` properties `es`, `fr`, `ar` (from the `world-countries` package).
- Event text: all events carry `tx` / `dx` for `es`, `fr`, `ar` (machine-assisted via Google Translate, curated where possible). Corrections are welcome; keep them aligned with the English and Chinese versions.
- Arabic sets `dir="rtl"`; test panels, cards and the timeline in RTL.

## Validate

```bash
node scripts/validate-data.mjs
```

The validator checks required fields, coordinates, categories/scenes/regions, unique slugs, links, theatre keys against event slugs, country codes, and the historical manifest. Warnings are acceptable for disputed or micro-territory ISO codes; errors block a build.
